# KING-KHAN# 🍳 AI Fridge Chef (Streamlit + Gemini Flash)

An interactive web application built with Python, Streamlit, and Google's Gemini Flash model that turns random leftover fridge ingredients into gourmet recipes.

## Features
- **Custom Ingredient Input**: Input whatever items are about to expire in your fridge.
- **Dietary Filters**: Support for vegetarian, vegan, keto, gluten-free, and more.
- **Graceful Error Handling**: Validates empty text entries and missing API keys cleanly.
- **Powered by Gemini 1.5 Flash**: Delivers fast, creative, and structured recipe outputs.
